# SANGVAIL — Portfolio Screenshot Capture Instructions

Capture clean desktop screenshots (1440×900 recommended, 100% zoom) after starting the application with `.\run.bat` and signing in with `admin` / `admin123`.

Recommended filenames to save in this directory:

1. `overview-workstation.png` — **Overview** page showing horizontal top navigation, 6 KPIs, Needs Attention alerts, and operational charts.
2. `inventory-custody.png` — **Inventory** page showing unit-level custody ledger and reconciled stock matrix.
3. `requests-fefo.png` — **Requests -> Manage & FEFO Allocate** showing the FEFO Allocation Preview table and human-approval policy warning.
4. `expiry-monitor.png` — **Expiry** page showing component-specific expiry windows and wastage trends.
5. `forecasting-shortage.png` — **Forecasting & Shortage** page showing historical vs. forecasted demand chart, chronological MAE/RMSE table, and explainable shortage alerts.
6. `data-quality-centre.png` — **Data Quality** page showing the 100% score and 14-check integrity matrix.

> Do not include real credentials or personal information in screenshots. SANGVAIL displays a `DEMO` indicator across all pages to confirm synthetic data usage.
